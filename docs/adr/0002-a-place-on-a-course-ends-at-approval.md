# A place on a course ends when the Refund Request is approved

The buyer keeps the course while their Refund Request is Open and loses it the moment a Platform Admin approves it, not when the Refund is issued.

## Considered Options

- **When the request is raised**: rejected, because a buyer whose request is declined would have been locked out for nothing.
- **When the Refund is issued**: rejected, because a Failed Refund would leave the buyer holding both the course and an approved Refund Request, and it would tie the course to money movement that is handled separately.
