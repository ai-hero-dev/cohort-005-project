# Team Licence refunds are all-or-nothing, and Seats freeze while one is Open

A Refund is always the full amount paid, so a Team Licence with any Claimed Seat can't be refunded, and there are no partial refunds for its Unclaimed Seats. To stop a Seat being claimed between the request and the decision, a Team Licence's Unclaimed Seats can't be claimed while it has an Open Refund Request. If the request is declined they work again. If it's approved they can never be claimed.

## Considered Options

- **Let Seats be claimed while Open, and only allow Decline afterwards**: rejected, because the Team Admin's request would be quietly defeated by a colleague.
- **Refund part of the money for the Unclaimed Seats**: rejected, because it breaks "a Refund is always the full amount" and needs a per-Seat price.
